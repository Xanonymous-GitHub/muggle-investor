# 類股拆解

適用：使用者想知道最近一個收盤日的類股強弱、資金往哪裡去，或某個類股為什麼動。

## 步驟
1. 先呼叫 getMarketToday，確認資料日期（dataDate），再看大盤的漲跌家數與整體力道。
2. 呼叫 getSectorBoard（order 用 leaders），取強勢類股；再用 laggards 取弱勢類股，兩邊都看，不要只講好消息。
3. 使用者問的類股不在排行前幾名時，加大 limit 再查一次；仍然沒有就照實說排行裡看不到它。
4. 比較每個類股的當日漲跌（changePct）、近一個月漲跌（change1mPct）、成交值排名與漲跌家數：
   - 當日強、近一個月也強：趨勢延續。
   - 當日強、近一個月弱：可能只是反彈。
   - 漲停、跌停家數多：說明資金集中在少數個股，不代表整個類股都強。
5. 使用者提到不懂的詞（力道、廣度、漲停鎖死等），先呼叫 lookupTerm，再用白話解釋。
6. 需要背景時，呼叫 getLatestBriefing 看最新簡報怎麼描述同一天的行情。

## 回答時
- 開頭先講資料日期：這是收盤後的每日資料，描述的是那一天的樣子。
- 數字照系統提示的【事實規則】：引用工具回傳的數字，簡單的算術（強弱類股的差距、當日與近一個月的對照）可以做，寫清楚怎麼算。
- 是否對類股接下來的走勢表態、給出什麼建議，照系統提示【你的聲音】的規則；有表態時，把依據的訊號講出來。
- 明講不確定的地方：單日表現雜訊多，成分股少的類股特別容易被個股帶動。
