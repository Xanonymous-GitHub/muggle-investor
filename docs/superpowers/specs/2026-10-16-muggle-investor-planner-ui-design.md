# Muggle Investor 階段 3B：規劃頁畫面設計

這是 `2026-10-14-muggle-investor-planner-design.md` 的前端部分。後端（問卷計分、配置、試算、`POST /api/plan`、LLM 說明與 `GET /api/plan/explanation`）已完成並合併；這裡只描述使用者看到的畫面。標示「（使用者已決定）」的是使用者簽核或回答過的；其餘是我的決定，使用者可以否決。畫面草圖（用真實引擎輸出畫的）：https://claude.ai/artifact/E8PbfSDo7FssJLuADUvRQV 。

## 目的與原因

非專業使用者回答幾題，就看到「這筆錢怎麼分、怎麼放進去、過去這樣做的結果」，並用入門或專業的說法讀懂。所有數字由後端算好，畫面只負責呈現與老實標示限制。

## 目標

- 手機與桌機都好用，沿用既有的外框、淺色與深色主題、入門與專業視角、名詞晶片。
- 問卷的答案只存在使用者的裝置上；結果不儲存，每次開啟重新計算。
- 每個歷史數字都標示它的資料期間；不同等級的報酬不並排比較。
- 資料或答案讓正常流程走不下去時，畫面直接說原因與下一步。

## 非目標

- 登入、帳號、跨裝置同步答案、儲存結果。
- 分享或匯出結果、列印。
- 為個別使用者呼叫 LLM。
- 對個別標的給買賣建議。

## 反目標

- 為了拿到想要的等級而修改答案（填答時不顯示等級）。
- 把不同期間的報酬排在一起比較，或暗示某個等級「比較划算」。
- 把「只有股票」那段較長歷史的數字，說成是建議配置的結果。
- 在畫面上寫出沒有來自後端的數字或預測。
- 沒有標示資料期間與「過去表現不代表未來」的試算畫面。

## 使用者已決定的事

- 草圖整體方向（問卷、結果、桌機雙欄、特殊情況畫面）。
- 等級 1 維持名稱「保守」；畫面照實顯示該等級自己的最大回撤與最差一年，並加一句固定說明：債券部位是 20 年期以上美國公債 ETF，測試期間仍然下跌約兩成（數字來自回應）。
- 「只有股票」的較長歷史（2007 年起）在入門與專業視角都以切換鈕呈現在歷史圖上，並標示它自己的期間；LLM 說明文字只談建議配置那一段。

## 我的決定

- **位置：** 路由 `/plan`，導覽多一個「規劃」（計算機圖示），在「族群」與「名詞」之間。手機底部導覽從三項變四項。服務工作者安裝時預先快取 `/plan`。
- **離線：** `POST /api/plan` 不快取。離線時顯示「需要連線才能試算」，答案仍保留在裝置上。
- **答案儲存：** 瀏覽器本機儲存空間，鍵名 `muggle.plan.draft.v1`；讀取時逐欄位容錯（壞的值只丟掉該欄位），寫入失敗不影響畫面。只存答案，不存結果。
- **問卷：** 手機一題一頁，上方進度點，選了自動前進，可以往回；最後一頁是四個金額。桌機（寬螢幕）九題在同一頁。金額為 0 到 1,000,000,000 的整數，`可投入 + 每月投入` 必須大於 0，離開欄位時加上千分位，錯誤就地顯示。
- **結果順序：** 風險等級（五格量表；承受能力與意願如何得出等級；資金一年內要用時的上限說明）→ 緊急預備金 → 配置（疊色條加每份的金額、比例、標的與備選）→ 投入節奏 → LLM 說明 → 歷史（切換、圖、三種投入方式表格、最大回撤、最差一年、波動度）→ 試算前提（後端回傳的句子）→ 兩句固定聲明（「過去表現不代表未來。」「以上為資料整理與教育說明，不構成投資建議。」）。桌機為雙欄，右欄（等級、說明、前提）固定在視窗內。
- **特殊情況：** 預備金不足時只顯示預備金計畫；歷史資料不足一年時只顯示配置與節奏；債券或高股息標的暫時不合格時（後端 `warnings`）在配置上方顯示橫幅；資料讀取失敗時顯示重試；說明還沒產生時顯示「說明還在準備中」，不當作錯誤。
- **圖表：** shadcn 的 chart（Recharts），依原簽核規格。圖旁有同內容的表格，鍵盤與輔助技術讀表格。顏色使用新增的主題變數（淺色與深色各一組），紅漲綠跌的慣例不變。
- **視角差異只在文字：** 入門用白話標籤（例如「最深曾經跌」「最差的連續一年」「換算成每年」），專業用原名詞（最大回撤、最差滾動十二個月、XIRR）。同一份程式碼，標籤放在同一個內容檔，標示待使用者審閱。
- **返回鍵：** 結果畫面用畫面上的「修改答案」回到問卷（元件狀態，不寫入網址）。
- **不確定的數字：** `xirr` 或 `worstYear` 為空時顯示「—」並說明「期間太短，無法計算」。

## 資料來源（後端已有）

- `POST /api/plan`：請求與回應見 `src/planner/schema.ts`（`kind: plan | reserve_only | insufficient_history`）。金額為整數元，歷史序列是月底資料點。
- `GET /api/plan/explanation?level=1..5&lens=beginner|pro`：該等級該視角的 LLM 說明與引用的名詞；404 代表還沒有。
- `GET /api/glossary`：名詞庫（名詞晶片與面板）。

## 技術限制

vinext（App Router）、TypeScript、Bun、Biome、shadcn/ui（Tailwind v4）、Zod、Serwist；所有依賴使用最新版。程式碼遵循現有慣例，附測試。`src/ui/**` 只以 `import type` 引用伺服器型別。
