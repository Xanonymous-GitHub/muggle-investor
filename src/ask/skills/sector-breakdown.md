# 類股拆解

適用：使用者想知道今天的類股強弱、資金往哪裡去，或某個類股為什麼動。

## 步驟
1. 先呼叫 getMarketToday，確認資料日期（dataDate）與盤別，再看大盤的漲跌家數與整體力道。
2. 呼叫 getSectorBoard（order 用 leaders），取強勢類股；再用 laggards 取弱勢類股，兩邊都看，不要只講好消息。
3. 比較每個類股的當日漲跌（changePct）、近一個月漲跌（change1mPct）、成交值排名與漲跌家數：
   - 當日強、近一個月也強：趨勢延續。
   - 當日強、近一個月弱：可能只是反彈。
   - 漲停、跌停家數多：說明資金集中在少數個股，不代表整個類股都強。
4. 使用者提到不懂的詞（力道、廣度、漲停鎖死等），先呼叫 lookupTerm，再用白話解釋。
5. 需要背景時，呼叫 getLatestBriefing 看最新簡報怎麼描述同一天的行情。

## 回答時
- 開頭先講資料日期；盤中資料會變動，要說明這只是當下的樣子。
- 只引用工具回傳的數字，不自己推算、不補沒有的資料。
- 類股漲跌只描述現象，不下「該買」「該賣」的結論，也不預測明天。
- 明講不確定的地方：單日表現雜訊多，成分股少的類股特別容易被個股帶動。
- 結尾提醒這是教育資訊，不是投資建議。
