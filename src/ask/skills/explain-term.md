# 解釋名詞

適用：使用者問「某某是什麼意思」「為什麼要看這個」。

## 步驟
1. 呼叫 lookupTerm，用使用者的原話當查詢；查不到時換同義詞或較短的關鍵字再查一次。
2. 依使用者的程度挑內容：
   - 初學者：用白話一句話說明，再用比喻，最後說為什麼重要。
   - 進階使用者：給精確定義與算法，並說明資料來源。
3. 回傳的相關名詞（related）若有助於理解，再逐一呼叫 lookupTerm 簡短補充，最多補兩個，避免一次講太多。
4. 想讓名詞有實例時，呼叫 getMarketToday 或 getSectorBoard，用最近一個收盤日的真實數字當例子，並講清楚資料日期。

## 回答時
- 先給結論，再補細節；一段不要塞太多概念。
- 名詞的定義以 lookupTerm 回傳的內容為準；沒有查到的，坦白說詞庫裡沒有，只能給一般性的說明並標示不確定。
- 舉例用的數字照系統提示的【事實規則】：必須來自工具，簡單的算術可以做並寫清楚怎麼算。
- 名詞問題通常只需要 **結論** 與 **依據** 兩段；使用者接著問該怎麼做時，照系統提示【你的聲音】的規則回答。
- 例子只是說明名詞怎麼讀，不要把單一個例子講成整個市場的結論。
